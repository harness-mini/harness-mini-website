# SEO best practices (Vercel SEO starter, adapted)

Add the SEO surface the site lacks, following the
[Vercel Next.js SEO starter](https://vercel.com/templates/next.js/seo-starter)
and Next 16 metadata conventions (verified in `node_modules/next/dist/docs`).

## What's already good (don't touch)
- Rich `layout.tsx` metadata: `metadataBase`, title template, description,
  keywords, openGraph, twitter.
- `opengraph-image.tsx` + `twitter-image.tsx` (dynamic OG via next/og).
- Fully static prerender (good for crawlers).

## Gaps → three issues
- **#13 sitemap + robots** — neither exists (the starter's core).
- **#14 canonical URLs** — no route sets `alternates.canonical`.
- **#15 JSON-LD** — no structured data.

Out of scope (delete before you add): PWA web manifest (needs new icon assets;
more PWA than SEO), per-page OG overrides (root OG already covers it).

- Derive sitemap URLs from `DOCS_NAV` (single source; new docs route → sitemap
  updates automatically).
- `SoftwareApplication` (DeveloperApplication, free Offer, `codeRepository`, MIT)
  is the most rich-result-friendly type for an open-source CLI tool.
- `eval: L1` — additive, standard Next conventions; not architecture/security.
